# Claude: artefacto con asistente, o Proyecto

## Opción A · Artefacto con asistente (lo más simple para quien lo usa)

Un artefacto de Claude es una página que se comparte por link. Puede traer un asistente adentro: la persona escribe la carrera y el contexto, y Claude responde en la misma página con los datos que la página tiene cargados.

Cómo se arma (lo hace quien mantiene el radar, una vez):

1. En Claude Code, dentro de este repositorio, pedir: *«Publicá un artefacto con el radar de interés y un asistente, usando `docs/data/paquete-chat.md` y `chat/INSTRUCCIONES_CHAT.md`»*.
2. Compartirlo desde el menú **Share** del artefacto con las personas que lo van a usar.

Límites: el asistente de un artefacto no navega ni mide. Responde con los datos que trae la página. Cada persona usa su propia cuenta de Claude.

## Opción B · Proyecto de Claude

1. Crear un Proyecto en claude.ai.
2. Pegar el contenido de `INSTRUCCIONES_CHAT.md` en las instrucciones del proyecto.
3. Subir `docs/data/paquete-chat.md` como archivo del proyecto. Volver a subirlo cuando se midan temas nuevos.
4. Compartir el proyecto con el equipo.
