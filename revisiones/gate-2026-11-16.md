## C10. Diferencias Python vs JS

1. **Real (afecta al modo en vivo).** `transformar.py` hace `clave.replace(tema_norm, " ")` (reemplaza **todas** las ocurrencias) y `nucleo.js:consultaEnVivo` hace `norm.replace(temaNorm, " ")` con string, que reemplaza **solo la primera**. Con frases publicadas reales: «inteligencia artificial inteligencia artificial» → Python `otros`, JS `temas`; «inteligencia artificial o inteligencia artificial» → Python `otros`, JS `comparar`. Los datos guardados salen del colector Python, así que no están afectados; solo el modo en vivo clasificaría distinto esas frases (2 de 1.905 en este corpus).
2. **De entrada, menor.** `comun.limpiar_tema` quita el prefijo «Consulta:» y `limpiarTema` de JS no. Ejemplo: «Consulta: ciencia de datos» → Python `ciencia de datos`, JS `consulta ciencia de datos` (el prefijo pasa a ser parte del tema).
3. **Borde sin efecto en el corpus.** Python mide `len` del texto ya recortado con `.strip()` (`validar.py`); JS mide `texto.length` sin recortar (`nucleo.js:62`). Solo cambia con textos pegados al límite de 120 caracteres con espacios en los bordes.
4. `normalizar`: 0 diferencias en las 1.909 frases (Python quita todo `Mn`; JS quita U+0300–U+036F. Equivalentes para letras latinas).
